LINDELL STREAMS LIVE 0.4.0 - MAC VST3 TEST BUILD

Quit REAPER. Copy the entire Lindell Streams Live.vst3 bundle into:
/Library/Audio/Plug-Ins/VST3/
(or ~/Library/Audio/Plug-Ins/VST3/ for just your user account).

The development build is ad-hoc signed, not Apple notarized. If macOS blocks
this exact build, approve it in Privacy & Security, or remove only its quarantine:
xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Lindell Streams Live.vst3"

Restart REAPER and rescan VST3 plugins. Insert LAST on your stereo master bus.
The host audio passes through unchanged; no reported plugin latency.

CONNECT
1. Sign into https://lindell-streams.com/ and open your playlist's Live panel.
2. Copy its playlist Share link, and create a PRIVATE connection key.
3. Use the PASTE button beside each field (or Command-V), then CONNECT. Never send the private key to a listener.
4. Confirm the playlist title, then press GO LIVE.
5. Listeners open the normal playlist share link and select Live / Listen Live.
6. Use STOP BROADCAST to end the session. Closing the editor does not stop it.

The private key stays in memory and is not saved in projects. The playlist link
is saved with the project and gives its holders listening access.
Recall/duplication, host reconfiguration, bypass, offline bounce and missing host
audio stop the sender. Restart is always manual.

Outgoing audio: Opus stereo, 48 kHz, 192 kbps target VBR. A sinc resampler converts
only the outgoing copy at other host rates. This is NOT a lossless stream.
Website protocol: lindell-live-webrtc-v1 (v22 Live update). No website deployment
or relay provisioning occurs when installing this plugin. The saved v22 website
must already be installed. At most eight peer-to-peer listeners.

This Mac build supports UDP TURN and verified TURN-over-TLS, including TCP 443.
Your website must provide temporary relay credentials. No relay account is
included. TLS certificates are checked against macOS system trust.

EXTERNAL-NETWORK TEST
1. Enable Test TLS relay (TCP 443) before connecting.
2. Connect, then Go Live. WAITING means no listener is connected yet.
3. On your phone with Wi-Fi off, open the playlist and press Listen Live.
4. ON AIR means a listener connection is established.
5. If it fails, use COPY DIAGNOSTICS and send that text. It excludes private keys.
The optional Website/live.js adds listener diagnostics; back up the deployed file
before replacing it. Leave the private Cloudflare credentials in their current
server location.
Local native-to-Chromium stereo tests are part of CI. Your production playlist,
external networks, REAPER and long-running sessions still need user testing.
